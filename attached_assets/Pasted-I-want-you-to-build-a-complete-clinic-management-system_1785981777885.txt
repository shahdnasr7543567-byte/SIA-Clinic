## 🧩 REQUIRED MODULES

### 1. Authentication Module
- **Login Page:** Email + Password, with show/hide password toggle, primary button, "Create Account" and "Forgot Password" links
- **Register Page:** For patients only (name, email, mobile, password, confirm password)
- **Role-based redirect:** Admin → /admin, Doctor → /doctor, Receptionist → /reception, Patient → /patient
- **Protected Routes:** All pages require authentication. Role-based access control (RBAC)
- **Zustand store:** For user data (authStore)
- **Axios interceptors:** For JWT token management in localStorage
